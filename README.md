# Anki Automations

A collection of command-line tools that streamline Anki flashcard creation and management using AI-powered automation. These tools work together to provide a complete workflow from content creation to Anki deck integration.

## 🚀 Quick Start

```bash
# Generate flashcards from text
fcb "The mitochondria is the powerhouse of the cell"

# Add generated flashcards to Anki
fca biology

# Create language flashcards from dictionary definitions  
lfcb "cat NOUN a small domesticated carnivorous mammal"
```

## 📦 Installation

### Prerequisites
- [Claude Code](https://docs.anthropic.com/en/docs/claude-code/overview) - AI-powered command-line tool
- [AnkiConnect](https://ankiweb.net/shared/info/2055492159) add-on for Anki (ID: 2055492159)
- Anki desktop application
- `jq` command-line JSON processor (`brew install jq` on macOS)

### Setup
```bash
# Clone the repository
git clone https://github.com/yourusername/anki-automations.git
cd anki-automations

# Make all scripts executable
chmod +x fcb fca fcc lfcb

# Add to your PATH (choose one method)

# Method 1: Add to ~/.bashrc or ~/.zshrc
echo 'export PATH="$HOME/anki-automations:$PATH"' >> ~/.zshrc
source ~/.zshrc

# Method 2: Create symlinks in a directory already in PATH
ln -s $(pwd)/fcb /usr/local/bin/fcb
ln -s $(pwd)/fca /usr/local/bin/fca
ln -s $(pwd)/fcc /usr/local/bin/fcc
ln -s $(pwd)/lfcb /usr/local/bin/lfcb
```

### Editor Configuration
The `editor` file configures which editor opens when reviewing generated content. By default, it uses Windsurf. To customize:

```bash
# Edit the editor configuration
nano editor

# Change PREFERRED_EDITOR to your preferred editor
export PREFERRED_EDITOR="code"  # VS Code
export PREFERRED_EDITOR="vim"   # Vim
export PREFERRED_EDITOR="open"  # Default system app
```

## 🛠️ Tools

### fcb - Flashcard Builder
Generate AI-optimized flashcards from any text content using Claude's expertise in spaced repetition.

```bash
fcb [options] content
echo 'content' | fcb [options]
```

**Options:**
- `-b` - Generate Basic cards (default)
- `-c` - Generate Cloze cards
- `-r` - Read content from `~/fc-content.md` file  
- `-t "tags"` - Add comma-separated tags
- `-m "message"` - Custom instructions for Claude
- `-h` - Show help

**Examples:**
```bash
# Basic flashcard generation
fcb "The mitochondria is the powerhouse of the cell"

# Generate with specific tags
fcb -t "biology,cells" "The nucleus contains DNA"

# Generate cloze deletion cards
fcb -c "The mitochondria is the powerhouse of the cell"

# Use file content as input
fcc  # Creates and opens ~/fc-content.md for editing
fcb -r -t "biology"  # Generates cards from file content

# Custom Claude instructions
fcb -c -m "use multiple cloze deletions" "Complex biological process"

# Pipeline usage
echo "Photosynthesis converts CO2 and water to glucose" | fcb -b -t "biology"
```

**Output:** Saves flashcards to `~/flashcards.json` and opens in configured editor.

### fca - Flashcard Adder
Adds generated flashcards to Anki via the AnkiConnect API.

```bash
fca [deck_name]
```

**Arguments:**
- `deck_name` - Target Anki deck (default: `/general`)

**Examples:**
```bash
fca                    # Adds to /general deck
fca biology           # Adds to biology deck
fca "Spanish Vocab"   # Adds to Spanish Vocab deck
```

**Requirements:**
- `~/flashcards.json` file (generated by `fcb`)
- Anki running with AnkiConnect add-on
- Target deck must exist in Anki

### fcc - Flashcard Content Creator
Simple utility to create and edit the content file used by `fcb -r`.

```bash
fcc
```

Creates `~/fc-content.md` if it doesn't exist and opens it in your configured editor.

### lfcb - Language Flashcard Builder
Specialized tool for formatting dictionary definitions into clean HTML flashcards for language learning.

```bash
lfcb "dictionary definition text"
echo 'definition' | lfcb
```

**Features:**
- Formats dictionary definitions with proper HTML structure
- Handles pronunciations, word types, meanings, and examples
- Underlines target words in examples
- Automatically opens Anki Add Card dialog
- Uses `languages::en` deck by default

**Examples:**
```bash
lfcb "cat NOUN a small domesticated carnivorous mammal"
lfcb "run VERB to move swiftly on foot"
```

## 🔄 Typical Workflows


## ⚙️ Configuration

### AnkiConnect Setup
1. Install AnkiConnect add-on in Anki (ID: 2055492159)
2. Restart Anki
3. Ensure Anki is running when using `fca` or `lfcb`

### Note Types Required
- **Basic + Extra**: For basic flashcards (fields: Front, Back, Extra)
- **Cloze**: For cloze deletion cards (fields: Text, Extra)  
- **Basic**: For language flashcards (fields: Front, Back)

## 🔧 Troubleshooting

### Common Issues

**"flashcards.json not found"**
- Run `fcb` to generate flashcards before using `fca`

**"Cannot connect to AnkiConnect"**
- Ensure Anki is running
- Verify AnkiConnect add-on is installed and enabled
- Check that no firewall is blocking port 8765

**"Deck doesn't exist"**
- Create the target deck in Anki before adding cards
- Use exact deck name (case-sensitive)

**"Note type doesn't exist"**
- Ensure required note types exist in Anki
- Default note types can be created in Anki's Tools > Manage Note Types

**"jq command not found"**
```bash
# macOS
brew install jq

# Linux (Ubuntu/Debian)
sudo apt install jq

# Linux (CentOS/RHEL)
sudo yum install jq
```

### Debug Mode
For debugging AnkiConnect issues, you can test the connection manually:
```bash
curl -X POST http://localhost:8765 -d '{"action": "version", "version": 6}'
```
